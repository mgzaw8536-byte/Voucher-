MZ Creative Art Voucher — iPhone/iPad Web Edition

This folder is a browser/PWA edition of the supplied Customer Android project.
The original Android project is not modified.

Use:
1. Upload this folder to an HTTPS web host (GitHub Pages, Netlify, etc.).
2. Open index.html through the HTTPS site in Safari on iPhone.
3. Safari -> Share -> Add to Home Screen.

Important:
- Voucher/settings data use browser localStorage.
- Backup/Restore uses the browser file picker/download.
- Voucher image saving uses browser download/share behavior.
- The Android-only device-bound activation screen cannot use Android_ID on iOS.
  Therefore this web edition does not pretend to provide Android license binding.
  The original Android activation code remains unchanged in the Android project.
